# Life philosophy

> **Historical (v1).** This document describes the original
> single-owner build. The v2 revamp made the product universal —
> see `README.md`, `docs/data_model.md`, and `docs/roadmap.md`
> for current behavior.

**Money = scoreboard. Curiosity = engine. Freedom = actual goal.**

This app exists for one reason: to keep the operator pointed at the thing
that compounds.

## The triad

- **Money is the scoreboard, not the mission.** It measures whether the
  engine is producing. Surplus is tracked so it can be pointed at freedom,
  not so it can be admired. Spending rules exist because leaks are noise on
  the scoreboard.
- **Curiosity is the engine.** High-novelty, hunt-driven energy is an asset
  — the same trait that makes diffusion dangerous makes deep hunting
  possible. The app never shames curiosity. It captures it (the idea
  parking lot), cools it for 7 days, and points it at one hunt.
- **Freedom is the actual goal.** Not the job, not the streak, not the
  surplus. A freedom target (passive income + liquid net worth) sits at the
  top of the identity screen so the numbers always have a "why".

## The operating context

- One main hunt: **Kaizen growth**. Build mode is fenced. Growth mode first.
- The 6-hour/day W-2 job is the funding base, not the identity.
- Flipping is winding down. Sunk projects don't get new hours.
- Recovery is load-bearing. A 10.5 h/week decompress floor is tracked like
  a budget line, not like a treat. It cannot hit zero.
- Willpower is not the mechanism. Environment design is: a visible
  scoreboard, one daily kill-or-confirm experiment, reminders at fixed
  times, and a parking lot that makes "later" a real place.

## The daily loop

1. Morning command (8:00): one Kaizen action, one money constraint, one
   recovery action, one anti-diffusion reminder — generated from real data.
2. One experiment before research. One test. One verdict:
   kill / confirm / iterate.
3. Log hours against the weekly time budget. Available time is the real
   budget.
4. Money check (18:00): categorize spend. Undefined misc is fog.
5. Night review (22:00): recovery floor protected, verdict logged, ideas
   parked — not chased.

The Focus Integrity Score (0–100) compresses this loop into one number so
drift is visible the day it starts, not at the end of the month.
